Tech homepage notes

  • Quick Actions unchanged from production. "Submit a timesheet" (primary) and "Global Search" (secondary). Both are universal actions that apply to service AND project techs. Nothing project-specific lives here. This avoids confusing service techs who would otherwise see "Write Daily Log" and wonder if it applies to them.
  • Work Orders widget stays in its existing position directly below Quick Actions. Service is the dominant business line, so it gets the prime real estate below Quick Actions. Same widget Thor uses today.
  • New "My Projects" widget sits below Work Orders. For techs assigned to projects, this is their entry point. For pure service techs, it's empty or hidden.
  • Scoped to "My Projects" only. Filtered by team membership on the project. Shows projects the tech is actively assigned to. "View all" link in header for when they need to search beyond their assigned set.
  • Search field inside the widget lets them filter their list or find a project by name/ID.
  • Each project row shows: name, project ID, location, and a task pill summary (3 tasks, 2 tasks, etc). Blocked tasks bubble up with a red pill so the tech sees them at a glance.
  • Tap a project row opens the per-project tech view, where Write Daily Log and Submit Time live as big primary actions.

Why Daily Log is NOT in Quick Actions

  • Daily logs are project-specific by definition. They cannot exist without a project context.
  • Putting it in Quick Actions would create confusion: service techs would wonder if they need to write one, project techs would have two entry paths and need to figure out which to use.
  • Inside-project is the right home: tech taps project → sees Write Daily Log and Submit Time as the two big primary action cards. Total cost: 2 taps from home to log composer. Acceptable.
  • Service techs see exactly the screen they see today, just with a Projects widget added below Work Orders.

What's intentionally NOT here

  • No equipment-first navigation (that's elsewhere in app, unchanged)
  • No mascot character
  • No lime green
  • No project KPIs, milestones, change notices, or admin info
