Project List View notes

  • Entry point of the Projects module. This is the first screen the admin sees when clicking Projects in the sidebar. From here, they see company-wide statistics and click into individual projects (which loads the per-project view with the 8 tabs).
  • Brand converted from the lime-green alternate to the current Odin production brand. White sidebar with logo, dark topbar, blue accents, white cards with light borders. Same brand conventions as Overview, Daily Logs, Activity, etc.
  • NO 8-tab row here. The tab row only appears INSIDE an individual project. This is the parent page, so it shows the page title bar directly under the topbar.
  • Sidebar Projects item is expanded showing its three sub-items: Projects (active), Add project, Image Library. Matches the original alternate-brand version exactly.
  • Search and Add Project sit at the top right. Search is a rounded pill input with a search icon. Add Project is a blue primary button.

KPI section

  • Primary KPI row (4 big tiles). The four most important company-wide numbers: Total Projects (neutral, with grid icon), Active (blue tint with clock icon), On Hold (amber tint with pause icon), Completed (green tint with checkmark icon). Each tile has a category icon top-right, big 36px value, sub-label below, and a thin blue gradient band at the bottom. Hover: subtle shadow lift.
  • Secondary row (2 small task tiles + Status donut). Total Tasks and Completed Tasks shown as smaller tiles. The Status donut card spans the remaining two columns of the row, getting substantially more space than before. The donut is now 130px (was 110px) and the legend uses a 2-column grid for tighter layout.
  • Donut card upgraded. Header has a category icon and "Status breakdown" title. Legend reorganized into 2 columns (Active + Completed in row 1, On Hold + Cancelled in row 2) so all four states fit horizontally. Center of the donut shows the active count and "project" label. Foot line: "3 tasks across 1 active project".
  • Default Team Members and Default Project Folders cards removed from this screen. Those settings are handled elsewhere in Odin (likely in account settings or admin config). Removing them gave the KPI tiles room to breathe.

Projects table

  • Standard columns: Project (clickable, navigates to per-project Overview), Code (monospace), Client, Manager, Status (pill), Start Date, End Date, Team (badge with count), Progress (bar + percentage), Actions (view + delete).
  • Project name is clickable in blue, hover underline. Clicking takes the admin to the per-project Overview tab.
  • Status pill color-coded by state: Active (green), On Hold (amber), Completed (purple), Cancelled (red with no example shown).
  • Progress bar with percentage on the right. Zero progress uses muted grey; positive progress uses blue.
  • Actions column: eye icon (view, navigates to project Overview), trash icon (delete, with confirmation modal not shown here).
  • Pagination: Per page dropdown (25 default, 50, 100 options), "X - Y of Z items" counter, prev/next arrows.

What's intentionally NOT here

  • No alternate brand colors. No lime green anywhere.
  • No Default Team Members or Default Project Folders cards (moved elsewhere in Odin).
  • No 8-tab row.
