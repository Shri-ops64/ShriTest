Project Log Detail · D-028 implementation notes

  • One file, three states. Mandeep builds one route (/projects/[id]/logs/[logId]) with three template variants based on the log's type field. This single mockup file shows all three states stacked for visual reference; in production users see only the one detail page they navigated to.
  • Daily Tech Log detail (State 1). Light field set: summary text, photos, hours, location, tasks referenced. No confidential treatment needed.
  • Foreman Report detail (State 2). Richer weekly-report content: project health from foreman's view, accomplishments, next week goals, schedule status, manpower, subtrade status (7 hardcoded subtrades), materials concerns, safety, three 1-10 ratings (Housekeeping / Project confidence / Customer relationship per Jun 9 Justin add), photos, free-form comments. All visible to the team.
  • Supervisor Report detail (State 3). Audit-style content: site visit info, supervisor's own health assessment, Thor Standards (now 4 categories: Workmanship / Site cleanliness / Productivity / Customer relationship), safety, schedule, Top 3 risks, support requested, photos. Plus the confidential block.
  • Confidential block (D-026). Two fields stay restricted: Foreman Performance rating, and Verification of Foreman Report accuracy. Rendered in an amber-tinted block with a "Confidential" label so the audience-restricted nature is visible. The block renders only for users where canViewSupervisorAuditContent(user, project) = true (PM, Supervisor on this project, global admin, global super-admin). For other users the entire block is omitted from the page.
  • Customer Relationship is NOT confidential (Jun 9 clarification). It appears in Thor Standards as a 4th row on Supervisor Report and as a 3rd 1-10 slider on Foreman Report. Visible to the team.
  • Header actions. Export PDF and Edit. No "Mark Reviewed" anywhere (no approval workflow per D-018). Delete lives in the row's context menu on the list view, not on the detail page (intentional friction).
  • Back link top-left returns to the Project Logs list. Standard breadcrumb pattern in the top bar also navigates back.
  • Page chrome matches the rest of the admin Project Module (same topbar, same project breadcrumb pattern). The detail page is part of the same module, not a separate route.
