Activity is the timeline. Everything that happens on the project is logged here automatically. Use Posts for team updates and Decisions to log permanent choices.

Activity tab notes

  • Two visual treatments. Human posts get the full block layout with initials avatar and body text. System events get a light single-line treatment with a small colored icon. The eye flows over system noise to find human content.
  • Every project event lands here. Daily log submitted, task status changed, time entered, PCN raised, asset uploaded, milestone reached, client report sent. Single source of truth for "what happened."
  • Inline photo thumbnails on relevant system events. Daily log submissions and image uploads show small thumbnails (28×28) inline before the timestamp. Lets admins eyeball photo content without clicking in.
  • Color-coded icons. Green for tasks, blue for daily logs and reports, amber for change notices, purple for assets, grey for time. Visual category at a glance.
  • Blocked tasks highlighted. Red icon and inline status badge so blockers stand out in the timeline.
  • Composer is Facebook-style. Single "Share an update with the team" input. No type selector, no Decision type. Posts are just posts; "decisions" are just posts that happen to say "we decided X" in the body.
  • Filter chips cover all event sources. All / Posts / Tasks / Daily Logs / Change Notices / Time / Assets. Single-select. Default is All.
  • Date grouping with section headers. Today / Yesterday / specific dates.
  • Right column shows event mix. Helps the admin understand the project's pulse over the last 7 days.
