Project Time tab notes

  • Mirrors the company-wide Timesheets Log module pattern with project-scoped tweaks. Same overview cards, same filters block, same filtered summary, same table chrome. Reuses the existing component library; Mandeep doesn't have to build new components, just point this view at a project-scoped query.
  • Project-to-date totals, not all-time. The overview cards show this week / last week / this month / last month for the project specifically. Same period semantics as Timesheets Log but the data is filtered to this project's entries only.
  • Filtered Summary header reads "Project-to-date" rather than the company-wide "Year to date." Reflects the lifetime of the project, which is shorter than a calendar year.

Filters that differ from the company-wide Timesheets Log

  • Dropped: Client (always the project's client, redundant), Location (project location is constant), Work Order (this is a Project, not a Work Order), Job Status (a Work Order concept, doesn't apply to projects).
  • Added: Task filter. Lets the PM see hours by task, which is useful for est-vs-act analysis when a task looks like it's running over.
  • Kept: Date, Date range, Type, Employees, Department, Status. Standard.

Table columns that differ from the company-wide log

  • Dropped: WO/Project # column (we're already inside the project; redundant), Client/Location column (same reason), Job Status column (Work Order concept).
  • Added: Task column. Shows the task each entry was attributed to, with the task's status as a sub-line. Tech-created drafts get the amber "Draft" pill so the PM can see at a glance that this hour was logged against a draft task awaiting review. Entries that the tech deliberately marked as Other render with a dashed-circle icon and "Other" text, mirroring the mobile picker affordance.
  • Kept: Employee / Dept, Type (Billable/Non-billable pill), Date, Hrs, OT, Total, Status (Submitted/Pending/Approved dot), Actions (edit / delete / view).

How this connects to other parts of the system

  • Same underlying records as the company-wide Timesheets Log. No duplicate writes. An entry created via mobile Submit Time, or via the desktop Timesheets module, or via the project Daily Log composer, all land in the same timesheet table. This tab is a filtered query.
  • Hours roll up to the Tasks tab. Each row's task linkage is what powers the est-vs-act bars on the Tasks tab. If an entry has no task (Kyle's row above), it counts toward the project's total but not toward any specific task's actual hours.
  • Draft-task entries still count toward project totals. Sam's "Replace damaged shut-off valve" draft task entry contributes 1:30 to the project's Total hrs even though the task itself is awaiting PM review. The hour was worked; the question is only how it gets attributed in the breakdown.
  • Export and Export Payroll at the top right behave the same as the company-wide module. CSV download, payroll-formatted export for accounting.

Out of scope for v1

  • Company Time grid view (weekly grid by employee, the second view in the Timesheets module). v1 is list view only on this tab. Probably v1.1 or v2.
  • Bulk approve / bulk reassign for selected rows. The row checkboxes are visible but the bulk-action toolbar is not implemented in v1.
  • Jonas accounting integration. Pending Andrea conversation; export buttons emit CSV in v1.
  • Inline edit of entries from this view. Edit opens the existing entry edit modal/page.
