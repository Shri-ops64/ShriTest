Daily Log detail view notes

  • Read mode by default. Tap "Edit" in the app bar to switch to composer view (same screen as #1, with all fields populated).
  • Status pill prominent at top: "Reviewed by admin" (green) or "Awaiting admin review" (amber). Matters to techs because reviewed = admin saw it.
  • Submission timeline shown as small text: submitted time, reviewed time (if applicable).
  • "Add Photos" button in the Photos section header is the same affordance that the per-project view's "Add Photos" provides. Tapping it opens camera/library picker and attaches photos to THIS log (not just the project's Site Photos folder). Solves the "I forgot to add photos before submitting" case.
  • Photos shown in a 3-column grid (denser than the composer's 4-col since we want them more viewable in read mode). Tap any photo to view full-size.
  • Summary text preserves line breaks from what was submitted.
  • Hours display uses the same pink-red gradient icon as the Submit Time button on the project view, keeping visual continuity.
  • Tasks worked on are read-only here. Tapping a task row could navigate to the task detail screen (the next mockup) but doesn't edit the link from this view.
