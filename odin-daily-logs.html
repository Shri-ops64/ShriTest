Daily Logs tab notes

  • List + Detail layout. Left side is the log list, right side is the detail panel for the selected log. Clicking a row updates the detail panel. Mobile would collapse to list-only with detail as a separate route.
  • Date grouping. Logs are grouped by date with a sticky header strip. Today / Yesterday / specific dates. Same pattern as a typical timeline view.
  • Big date block on the left of each row. Mimics the Odin Work Orders date treatment but vertical. Helps scanning when many logs exist.
  • Photo thumbnails inline. 2-3 photos visible per row with a +N overflow indicator. Click any photo (or the row) to open the detail panel with the full gallery.
  • Filter bar at top. Date range, technician, task, unreviewed-only toggle, free-text search across log content. Active filters get a blue tint (consistent with the rest of Odin).
  • Summary strip above filters. Five lightweight stats: total logs, this week, unreviewed (highlighted amber if any), total photos, total hours from log submissions.
  • Detail panel actions. Mark Reviewed (primary) and Export (secondary). The amber Review banner makes the admin's required action obvious when a log is unreviewed.
  • Tasks referenced are links. Each tech-referenced task appears as a clickable row that jumps to that task in the Tasks tab.
  • Web-side composer is intentionally absent. Daily Logs are submitted by techs on mobile. The web side is for review and consumption only, as agreed.
