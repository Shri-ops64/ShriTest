Per-project tech view notes

  • Lands here from "My Projects" widget on the homepage. Tap a project row, this opens.
  • Project header mirrors the home hero treatment visually (dark gradient) for continuity, but is more compact since the tech already knows who they are. Shows project name, ID, location.
  • Two big primary actions at top: Submit Time and Write Daily Log. Side-by-side cards with colored icon, label, and tiny sub-label clarifying scope ("to this project", "for today"). These are the two things the tech does dozens of times a week. They earn the prime real estate.
  • "Submit Time" pre-fills the project on the existing TimeTracker form. The tech doesn't have to pick the work type or project again.
  • "Write Daily Log" opens the log composer with project pre-filled and today's date selected.
  • "My Open Tasks" section shows only this tech's own tasks on this project. Status dot, name, status label, due date. Blocked task gets red treatment and surfaces the blocking reason inline. Tap to view task detail.
  • "My Recent Daily Logs" section shows the 3 most recent logs this tech submitted to this project. Tap to view full log. Photo thumbs visible inline. This answers the "did I already document that?" question.
  • "My Recent Photos" section shows the photo grid (8 most recent), plus the prominent "Add Photos" button at the top of the section. This is the standalone photo upload affordance you asked about: photos drop straight into the project's Site Photos folder without requiring a daily log to be open.
  • Everything scoped to "mine." Tech only sees their own tasks, logs, photos. Other techs' work is invisible. Reduces noise and protects privacy.

What's intentionally NOT here

  • No team list (techs don't need to see who's on the project)
  • No project KPIs, hours-to-date, milestones, change notices
  • No activity feed, no other techs' content
  • No assets folder browser (just their own recent photos)
  • No activity feed, change notices, or client reports surfaces

The two paths a tech uses

  • For time: Home → My Projects → tap project → Submit Time (project pre-filled). OR Home → Submit a timesheet → pick Projects work type → pick project. Both paths work.
  • For daily logs: Home → Quick Actions: Write Daily Log → pick project. OR Home → My Projects → tap project → Write Daily Log (project pre-filled). Both paths work.
