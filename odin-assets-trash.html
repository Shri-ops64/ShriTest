Assets · Trash view

  • Same layout as the main Assets view, with the active folder switched to Trash. Helps users feel oriented (still in Assets, just looking at deleted items).
  • Info banner at top explains the 30-day auto-purge rule and that permanent delete is admin-only. Sets expectations before the user takes destructive action.
  • "Empty Trash" link on the right of the banner (red, admin-only). Confirms with a modal before purging everything. Hidden or disabled for non-admins.
  • Trashed file cards are visually subdued (grayscale-filtered preview, reduced opacity) so it's obvious these aren't live files.
  • "From [original folder]" shown in the file meta so users know where to find it if they restore.
  • Deleted by + date on every card so the audit is visible at a glance.
  • Auto-purge countdown is the key affordance. Color-coded:
    • Grey/normal: 8+ days remaining
    • Amber/soon: 3-7 days remaining
    • Red/urgent: 0-2 days remaining (last chance to restore)
  • Two action buttons per card: Restore (any user with edit access) and Delete Forever (project admin only). For non-admin users, Delete Forever would be disabled with a tooltip explaining the permission requirement.
  • No bulk actions in v1. Items are restored or deleted one at a time. Bulk select + restore/delete is a v1.1 consideration.
  • Empty state for an empty trash: "Trash is empty. Items moved to Trash from this project will appear here for 30 days before being permanently removed."
