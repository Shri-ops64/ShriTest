Section 7.10 · Submit Time (Foreman/Supervisor)

Desktop conversionv1

Converted from mobile mockup Built from the mobile Submit Time screen, adapted to the established desktop chrome (nav, breadcrumb, this annotation rail) and the same form + sticky summary rail pattern used for the Daily Tech Log Composer conversion.
Standalone time entry for roles that file no daily log (D-040) Technicians enter time inside the Daily Tech Log (D-036). Foremen and Supervisors file a weekly report instead, so they need a real place to submit project hours — this screen, carrying the same time-blocks-plus-allocation model as the log, minus the narrative and photos.
Same time model as the Daily Tech Log One or more time blocks (optional time range + hours stepper; "Add another time block" for a return visit), a Total on site, then hours-to-task allocation where each task gets its own hours and an "Other" line catches non-task work (oversight, walkthroughs, helping out). The live "X of Y hrs allocated" bar shows when the day is fully accounted for. Worked example: a supervisor's 8.0 hrs split as 2.0 + 1.0 on tasks and 5.0 on Other (oversight).
Single source of truth These hours feed the regular Odin timesheet directly — the leader does not re-enter them there. (Training point for the Thor team.)
Existing-timesheet attributes kept Billable / Non-Billable, Project (pre-filled, locked when entered from the per-project view), and Date — laid out as three fields side by side on desktop rather than stacked, since there's room.
Sticky rail replaces the mobile footer button Mobile pins a single "Submit Time" button to the bottom. Desktop moves it into the sticky right rail alongside a running summary (type, project, date, total hours, allocation status), consistent with the Daily Tech Log Composer's rail.
Who sees this Foreman / Supervisor: "Submit Time" on their per-project view opens this screen — it's their time entry. Technician: no separate Submit Time; techs enter time in the Daily Tech Log, so the tech per-project view drops this button entirely (D-040), avoiding double-entry. The universal TimeTracker path (Home, Emergency Service / Maintenance / Projects / Non-Billable) is unchanged for non-project work.
