Foreman Report composer (desktop · v1 modal)

  • Same fields as the mobile composer, laid out wider. Two-column rows where it makes sense (this week / next week side-by-side; schedule + manpower; RFIs + materials concerns; safety + ratings). Saves vertical scroll.
  • Modal overlay on top of the Project Logs page. Page chrome dimmed behind. Modal width 760px, scrolls internally if content exceeds viewport.
  • Triggered by "Compose Report ▾" dropdown at the top of the Project Logs page. The dropdown shows: Tech Log, Foreman Report, Supervisor Report. Each opens its own composer.
  • Field-level controls match mobile (health traffic-light, schedule pill row, subtrade traffic lights, RFI auto-list, 1-10 rating sliders).
  • Three footer actions: Cancel, Save draft, Submit report.
  • Photos use simple upload pattern on desktop, not a camera-first capture pattern (since desktop entry won't typically have a camera in hand). Drag-and-drop supported.
  • Desktop entry is the fallback path. Most foreman reports are submitted from mobile after walking the site. Desktop is for catching up later or for foremen who prefer keyboard entry.
