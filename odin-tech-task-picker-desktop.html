Shared component · Task Picker

Desktop conversionv1

Bottom sheet → anchored popover Mobile uses a bottom sheet with a scrim over the dimmed parent form, since a phone has no room to float a panel next to the field. Desktop has that room: the picker becomes a popover anchored directly under the Task field, opening on click and closing on an outside click or the × — no full-screen takeover. Shown here open over a Submit Time form's Task field, matching the mobile mockup's demonstration.
One consolidated picker, shared everywhere (June 2 direction, unchanged) Per Justin's direction, the task selector is identical wherever a single task needs linking — same content, same behavior — regardless of which desktop screen opens it.
Worth flagging: entry points may need a second look on desktop The mobile spec lists this as the shared component for the Submit Time form, the Daily Tech Log composer, and the RFI composer's Linked Task field. The desktop conversions already built for Submit Time and the Daily Tech Log Composer use an inline checklist ("Allocate hours to tasks," multi-select with per-task hours) rather than a single "Task" field — that's a different job (splitting one day's hours across several tasks) from this picker's job (linking one task to one record). This popover most directly replaces the RFI composer's "Linked task" field on desktop. Worth confirming with Justin/the team whether Submit Time and the Daily Log still need a single-task field anywhere, or whether the inline allocation list fully superseded it there.
Search at the top (unchanged) Primary discovery affordance — with potentially hundreds of tasks per project (Jonas cost items), search is essential. Filters the list as the tech types.
No Mine / All filter chips (June 2, unchanged) Tasks aren't assigned to individuals — they belong to the project and any staff can see and log time against them. Status grouping alone provides the structure.
Status grouping + est-bar + selected state (unchanged) In Progress at top (most likely target), then Blocked (visible but visually discouraged with the red icon and inline blocking reason), then Not Started. Complete hidden by default. Each row carries a small est-vs-actual bar; selected row gets a blue border, blue-soft background, and a filled checkmark circle.
The "Other" row (unchanged) Sits above the status groups with a dashed-outline icon and an "or pick a task" divider, so it reads as a deliberate no-task choice rather than a forgotten field. Especially important since techs can't create tasks — Other is the release valve; the PM later reassigns those hours to a real task or a new Jonas cost item. Saves with task_id = NULL; hours roll into project totals but not into any task's actual hours.
Cut from the prior spec, still cut (June 2) No "Create new task" affordance, no Create-New composer, no Draft pill/"Awaiting PM review" state, no Mine/All chips — techs cannot create tasks; all tasks are PM-created and live.
