Supervisor Report composer (desktop · v1 modal)

  • Same fields as the mobile composer, laid out wider. Two-column rows for visit info, health + confidence, foreman performance + verification, schedule + safety, support + comments.
  • Modal overlay on top of the Project Logs page. Page chrome dimmed behind. Same modal pattern used by Foreman Report and Tech Log composers (consistency).
  • Triggered by "Compose Report ▾" dropdown at the top of the Project Logs page.
  • Health rating and Confidence sit side-by-side with the one-line reason as a full-width input below. Lets the supervisor capture the overall picture quickly.
  • Foreman performance and Verification are side-by-side since they're both observations of the foreman. Discrepancies textarea below for the "Mostly" or "No" case.
  • Three Top 3 risks as stacked input cards with amber left-border accent. Forces three distinct risk statements rather than a single dumping ground.
  • Desktop entry is the fallback path. Most supervisor reports submitted from mobile during/after the site visit. Desktop is for catching up later.
