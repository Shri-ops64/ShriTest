Project Logs tab notes

  • Tab renamed from Daily Logs to Project Logs (D-022, Pass 5 lock). The tab now holds three log types: daily tech logs, foreman weekly reports, and supervisor weekly reports. Sub-tabs at the top of the list filter by type: All / Daily Tech Logs / Foreman Reports / Supervisor Reports.
  • Compose Report dropdown at top-right exposes the report composer entry points (New Foreman Report / New Supervisor Report). Daily Tech Logs are mobile-only and submitted by techs in the field, so there is no "New Daily Tech Log" option here on the admin side (removed Jun 9, D-032): there is no desktop tech-log composer for it to open. Whether an admin ever needs to log one is an open question with their team.
  • Full-page detail view on row click (D-028, Jun 9). Clicking any row navigates to odin-project-log-detail.html rather than expanding a side panel. The earlier side-panel pattern undersold the richer audit content in foreman and supervisor reports; a dedicated detail page gives each log type room to render its full field set. One detail surface, three template variants based on log type.
  • Date grouping. Logs are grouped by date with a sticky header strip. Today / Yesterday / specific dates. Same pattern as a typical timeline view.
  • Big date block on the left of each row. Mimics the Odin Work Orders date treatment but vertical. Helps scanning when many logs exist.
  • Photo thumbnails inline. 2-3 photos visible per row with a +N overflow indicator. Click any photo (or the row) to open the detail page.
  • Filter bar at top. Date range, technician, task, free-text search across log content. Active filters get a blue tint (consistent with the rest of Odin).
  • Summary strip above filters. Five lightweight stats: total logs, this week, logs today, total photos, total hours from log submissions.
  • No approval workflow on any log type. Per D-018 (Justin Jun 2), all log submissions post straight to the project. Edit/delete remain available to authors and PM after the fact.
  • Tasks referenced are links. Each tech-referenced task appears as a clickable row that jumps to that task in the Tasks tab.
  • Web-side composer is intentionally absent for tech daily logs. Tech logs are submitted on mobile. Foreman and Supervisor reports have both mobile and desktop composers because these are typically written after the field day at a desk.
  • Confidential supervisor content (D-026): Two fields on Supervisor Reports stay restricted to PM, the Supervisor on the project, and global admin/super-admin: Foreman Performance rating and Verification of Foreman Report accuracy. All other supervisor content publishes to the team. The list row itself shows the supervisor report row to everyone; the confidential fields render only on the detail page for users with permission.
