About this deck

Twenty mockups for the Project Module, organized in three parts: module entry point (Project List View), per-project admin tabs (Overview, Daily Logs, Activity, Change Notices, Assets, Client Reports), and tech mobile surfaces. Built in current production Odin brand: white cards, blue accents (#1d62d3), dark gradient hero, pink-red gradient action buttons (#f86077 to #ed1c24), lowercase "odin" wordmark with red dot. Type: Inter (UI), IBM Plex Mono (IDs).

To navigate: click any card to open the full mockup in a new tab. Each mockup has annotations on the right side explaining design decisions, state variants, and what's intentionally excluded. Read the specification document first for context, decisions, data model, phasing, and open questions. Read the README for current status and where to pick up.

For dev handoff: mockup filenames shown in monospace match the files in this package. The spec document references each mockup by filename. Three tabs in the spec (Tasks, Time, and the Time Tracking module) don't have dedicated mockups because they reuse or lightly extend existing production UI patterns.
